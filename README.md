# AI MindLog - Burnout Detector & Mental Health Journaling Assistant

AI MindLog is a smart mental health companion designed for ForgeHacks 2026. It leverages advanced AI to analyze unstructured daily journals, track stress triggers, and generate interactive visual emotional insights.

## 🛠️ Built With
- **Adaption Labs**: End-to-end data processing infrastructure, data refinement via Adaptive Data, and dynamic charting powered by Adaptive Interfaces.
- **Featherless AI**: Advanced open-source LLM orchestration (Meta-Llama-3) utilizing a high-capacity 256K context window for long-term historical journal analysis.
- **Python**: Core backend programming language.

## 🚀 Key Features
- **Unstructured Journal Ingestion**: Converts messy, emotional daily texts into clean, structured mental health datasets.
- **Deep Sentiment Analysis**: Extracts precise scores (1-10) for stress, anxiety, and happiness, along with identifying root burnout triggers.
- **Conversational Analytics**: Allows users or clinicians to interactively query and render emotional trend charts using natural language.
